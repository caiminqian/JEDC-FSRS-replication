# 真实数据校准规范 v2.1（B2 新 loss 定义，2026-10-24）

## 原则

- 旧 loss 不可复现（脚本丢失、X 项未识别），故不假装可比。
  本规范全程透明：每个数都有定义，断裂处在 v51 如实披露。
- 只用 pack 自带组件：`FSRS_Economic_Memory`（单课），不动其公式。
- 可识别的参数只有 S：α 与 severity 在本规范的单课衰减中不起
  作用（合成网格里 α 本来就几乎平坦），故沿用旧值
  （α=0.6、severity_crisis=0.5）并明确标注“未由真实数据重识别”，
  不编造让它们起作用的机制。

## 数据

- VIX：FRED VIXCLS 日频，1990-01-02 → 2026-10-22（已验，9603 行）。
- VXO：FRED VXOCLS 日频，1986-01-02 → 2021-09-23（仅用于 1987）。
- 假日空值（"."）按缺失处理：窗口按交易日计数，假日跳过。

## 事件与窗口

- 峰值日（事件内最大波动率日）：
  1987 → 1987-10-19（VXO 150.19）；2000 → 2000-01-01 至 2002-12-31
  内 VIX 最大日；2008 → 2008-11-20（80.86）；2020 → 2020-03-16
  （82.69）；2022 → 2022-03-07（36.45）。
- 窗口：峰值日 → 峰值后 779 个交易日，共 780 tick（与旧报告
  的 800 天口径近似，取整为 780 以便峰值对齐在 tick 0）。
  数据不足处按实际长度截断并记录。
- 基准 floor：峰值日前 60 个交易日的中位数。
- 参照曲线 R_ref(t) = clip((vol_t - floor) / (peak - floor), 0, 1)，
  vol_t 为当日 VIX（1987 为 VXO），t=0 为峰值日（此时 R_ref=1）。

## 模拟

- 单课 FSRS_Economic_Memory，S0 = 网格值，w17/w18/w19/w20 取 pack
  默认（1.8729/0.5425/0.0912/0.0658）。
- 冲击：仅在峰值日（tick 0）施加一次，等级由峰值分档：
  peak ≥ 80 → G=1；40–80 → G=2；25–40 → G=3；否则 G=4。
  （1987 VXO 150.19 → G=1；2008 80.86 → G=1；2020 82.69 → G=1；
  2022 36.45 → G=3；2000 峰值由代码在 2000–2002 内取最大后分档。）
- 模拟 R：冲击后 S 按 FSRS 更新，之后按公式衰减 779 tick。
  不施加后续冲击，不引入 contagion。

## Loss（新定义）

- MSE_event = mean((R_sim(t) - R_ref(t))^2)，t 取窗口内全部 tick。
- recovery_event = |days_sim(R<0.5) - days_ref(R_ref<0.5)| / 780，
  其中天数自峰值日起算；任一方窗口内未下穿 0.5 则记窗口长度。
- loss_event = MSE_event + recovery_event。
- 总 loss = 5 事件 loss_event 的均值（与旧总 loss 的均值形式一致，
  但分项定义不同，不可比）。
- 网格：S ∈ {35, 37, 40, 42, 45, 50, 60, 75}（扩到 45 以上，防
  边界最优重演）；α、severity 不进网格，沿用旧值。

## 产出

- `calib_real.py` + `calib_real_results.json`（每格每事件的
  MSE/recovery/loss、最优 S、loss 随 S 曲线）。
- 最优 S 确定后，dao 上重跑 grid/paired/ps_sweep/stress（与 v50
  同规模，仅 S 换新值），再写 v51。
